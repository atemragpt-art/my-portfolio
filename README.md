# Portfolio/Corporate Site

Сайт на Astro 5 с Tailwind CSS v4, TypeScript и Content Collections.

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения для Telegram Bot и SMTP.
