# Изображения для кейсов

Поместите изображения для карточек кейсов в эту папку.

## Требуемые файлы:

1. **case-1.jpg** - для кейса "ОПТИМИЗАЦИЯ ПРОЦЕССОВ ЧПУ"
   - Рекомендуемый размер: 800x450px (16:9)
   - Формат: JPG или WebP

2. **case-2.jpg** - для кейса "СРАВНЕНИЕ ЦИКЛОВ ПРОИЗВОДСТВА"
   - Рекомендуемый размер: 800x450px (16:9)
   - Формат: JPG или WebP

3. **case-3.jpg** - для кейса "КОНТРОЛЬ КАЧЕСТВА И СНИЖЕНИЕ БРАКА"
   - Рекомендуемый размер: 800x450px (16:9)
   - Формат: JPG или WebP

## Использование:

Изображения автоматически загружаются из Content Collections через поле `heroImage` в файлах кейсов.

После добавления изображений, они будут отображаться в карточках кейсов на главной странице.
